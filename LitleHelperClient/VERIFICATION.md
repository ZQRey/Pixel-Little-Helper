## Измерение ресурсов

Файл `artifacts/diagnostics.json`: 5 секунд прогрева, затем 30 секунд измерения. Помощник был перекрыт другими окнами; анимация остановилась после 8 начальных кадров, Z-order переставлялся один раз. Результат относится к этому окружению и этому сценарию.

| Метрика | Результат | Требование |
|---|---:|---:|
| Общий Working Set | 75,19 МиБ | 25–35 МБ RAM |
| Private bytes, выделенная приватная память | 19,64 МиБ | Не эквивалентно общему RAM |
| Средний CPU после прогрева | 0,143% | ≤0,1% |

**Строгий бюджет ресурсов из задания пока не выполнен.** Нельзя выдавать private bytes за общий Working Set. Для обязательных 35 МБ требуется дальнейший выбор/пересмотр стека, например нативный Win32, либо согласованный способ учёта общей и разделяемой памяти. Не выполнялись искусственное урезание Working Set и принудительные сборки мусора.

## Требуется пилот на целевой Windows

* Фактическая установка, обновление и полное удаление MSI, включая недоступные/перенаправленные пользовательские профили.
* Назначение пакета и удаление через доменную GPO.
* Реальные клики сквозь прозрачность, выделение значков рамкой, Win+D, Explorer restart и мониторы с разным DPI.
* Перетаскивание через мониторы, край экрана и 5-минутный сон.
* API с настоящим корпоративным сервером: адрес и аутентификация не предоставлены; проверялся локальный тестовый HTTP-сервер.
* Отдельные длительные замеры видимой Idle-анимации, Sleep и обращения к серверу на слабых ПК.

`desktopHitSamples=0` при открытых окнах не доказывает ни видимость, ни невидимость робота на свободном рабочем столе. Shell-адаптация удерживает его перед хостом значков, но не заменяет проверку на целевой оболочке.
