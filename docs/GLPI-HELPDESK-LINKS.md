# Ссылки на главной странице GLPI HelpDesk

На сайте http://glpi.gp1.loc/Helpdesk добавлены штатные плитки GLPI типа «Внешняя страница»:

| Название | Описание | Целевой URL |
| --- | --- | --- |
| DMED | Медицинская информационная система | https://krg.dmed.kz |
| EISZ | РПН, ИСЛО, ЕТА | https://www.eisz.kz |

В профиле Self-Service порядок: «Заявка», DMED, EISZ. Ссылки также добавлены в корневую сущность, откуда их наследуют профили без собственного набора плиток. Файлы GLPI не изменялись, дополнительные плагины не устанавливались. Настройки хранятся в базе GLPI.

## Добавление ссылки для обычных пользователей

1. Войдите в GLPI с административными правами. Если автовход выбирает обычного пользователя, откройте http://glpi.gp1.loc/?noAUTO=1 и войдите административной учётной записью. Для локальной учётной записи выберите источник «Встроенная GLPI», для доменной — «gp1.loc». В меню профиля выберите Super-Admin, если доступно несколько профилей.
2. Откройте **Администрирование → Профили → Self-Service**.
3. Выберите вкладку **«Поддержка домашняя страница»** — так она называется в текущем русском переводе. Прямая ссылка: http://glpi.gp1.loc/front/profile.form.php?id=1&forcetab=Profile%244.
4. Нажмите плитку **«Добавить плитку»** с плюсом.
5. Выберите тип **«Внешняя страница»** (External page).
6. Заполните название, описание и **целевой URL** (Target url). Указывайте полный адрес с `https://`, например `https://krg.dmed.kz`. При желании выберите иллюстрацию из встроенного набора.
7. Нажмите **«Добавить плитку»** в форме. Повторите для остальных ссылок.
8. Для изменения порядка перетащите плитки за значок захвата и нажмите **«Сохранить порядок плиток»**.
9. Проверьте http://glpi.gp1.loc/Helpdesk под обычным пользователем профиля Self-Service. Обновите страницу, если она уже открыта. Убедитесь, что плитка ведёт на правильный адрес и кнопка «Заявка» остаётся доступной.

Изменение плиток не выдаёт пользователю доступ к DMED или EISZ: авторизация на этих сайтах действует отдельно.

## Изменение и удаление

На той же вкладке нажмите существующую плитку, отредактируйте название, описание, адрес или иллюстрацию и сохраните изменения. Удаление выполняется из формы редактирования плитки. Не удаляйте плитку «Заявка», если хотите сохранить текущий способ подачи обращений.

## Общая главная страница и другие профили

Для общего набора откройте **Администрирование → Сущности**, выберите корневую сущность **КГП на ПХВ «Многопрофильная больница» УЗКО**, затем вкладку настройки домашней страницы Helpdesk. Добавление плитки выполняется так же.

Если у профиля есть хотя бы одна собственная плитка, GLPI использует набор профиля вместо общего набора сущности. Поэтому ссылка, добавленная только в сущность, не появится в текущем Self-Service. Чтобы будущая ссылка была доступна и там, и в общем наборе, добавьте её в обоих местах. Для другого профиля с собственными плитками повторите настройку в этом профиле.

Для возврата к автовходу откройте http://glpi.gp1.loc/?noAUTO=0.
