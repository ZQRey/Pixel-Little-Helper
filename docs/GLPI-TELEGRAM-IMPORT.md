# Заявки из GLPI в Telegram

В Control Center откройте настройки Telegram. В разделе «Заявки, созданные напрямую в GLPI» включите импорт и сохраните. Telegram-уведомления и управление заявками через бота должны быть включены; используется существующий токен, группа и тема.

При первом включении сервер запоминает текущий максимальный доступный ID заявки. Старые заявки не отправляются. Затем раз в минуту обрабатываются до 50 новых заявок. После остановки или перезапуска обработка продолжается с сохранённого ID. Заявки, уже добавленные помощником, не дублируются. Уже решённые, закрытые и удалённые обращения пропускаются.

Нажмите «Загрузить местоположения GLPI» и выберите филиал напротив нужного местоположения. Дочерние местоположения наследуют филиал ближайшего настроенного родителя. Их собственное название отображается как кабинет. Неизвестное местоположение не препятствует отправке: филиал и кабинет будут обозначены как неуказанные. Для остальных сотрудников действуют существующие ограничения обработки заявок по филиалам.

Для API-учётной записи GLPI нужны права просмотра всех нужных заявок, пользователей и местоположений, назначения исполнителя, добавления ответов и решений, изменения статуса. Импорт видит только заявки, доступные этой учётной записи и выбранной области GLPI. Адрес API и учётные данные берутся из существующих настроек GLPI.

Новая заявка сохраняется в Control Center вместе с очередью уведомления. В группу отправляются номер GLPI, заявитель, заголовок, описание, филиал и кабинет. Для свободной активной заявки отображается «Принять». Принятие проверяет актуальное назначение в GLPI и использует существующий процесс работы через личный чат бота.

Если заявку назначили или закрыли через GLPI, сервер обновляет кнопку уведомления в Telegram. Уже назначенная заявка не переназначается другим администратором через старую кнопку. Синхронизация кнопок доступна для уведомлений, отправленных после внедрения этой функции: их Telegram message_id сохраняется в базе.

Сбой GLPI не продвигает курсор мимо неимпортированной заявки; после восстановления обработка повторяется. Сбой Telegram не отменяет заявку и обрабатывается существующей очередью повторов. «Проверить сейчас» запускает импорт вручную; результат и время последней проверки видны в настройках.
