# Стилизация сообщений

Выделите текст в поле ввода и нажмите сочетание клавиш. В поле остаётся разметка, под ним отображается предпросмотр. Получатель видит оформленное сообщение в клиенте 1.2.67+ и актуальной веб-версии.

| Оформление | Клавиши | Разметка |
|---|---|---|
| Жирный | Ctrl+B | **текст** |
| Курсив | Ctrl+I | *текст* |
| Подчёркнутый | Ctrl+U | __текст__ |
| Зачёркнутый | Ctrl+Shift+X | ~~текст~~ |
| Код в строке | Ctrl+E | Обратные кавычки вокруг текста |
| Блок кода | Ctrl+Shift+E | Тройные обратные кавычки на отдельных строках |

Повторное применение снимает стиль. Без выделения вставляются маркеры с курсором между ними. Стили можно сочетать; жирный и курсив вместе — тройные звёздочки. В коде оформление и эмодзи остаются буквальным текстом. Для буквального маркера вне кода используйте обратный слеш.

Выравнивание строк: Ctrl+Alt+L — влево, Ctrl+Alt+E — по центру, Ctrl+Alt+R — вправо. Добавьте Shift, чтобы применить ко всему сообщению. В режиме строк без выделения меняется текущая строка. Перевод строки на границе выделения не включает следующую строку.

Выравнивание хранится в строках с обёртками [align=center]текст[/align] и [align=right]текст[/align]. Левое выравнивание удаляет эти обёртки. Формат передаётся в прежнем текстовом поле Body; миграция БД не требуется. Старые клиенты показывают разметку буквальным текстом. Пользовательский HTML не исполняется.

В настройках есть кнопка «Помощь стилизации». Максимум 4000 символов включает разметку. Применение стиля и выравнивания проверяет лимит до изменения текста. Enter отправляет сообщение; Shift+Enter вставляет строку.

Esc закрывает выбранный диалог, оставляя мессенджер открытым. Текст и вложения черновика сохраняются в памяти до закрытия мессенджера/страницы. Всплывающие окна закрываются первым нажатием. Esc отменяет активную запись голосового/видеосообщения; уже запущенная отправка продолжается.

Проверки: общие fixtures tests/message-formatting-cases.json, Node tests/message-formatting.test.cjs, браузерный tests/message-formatting.browser.cjs с полностью изолированным API и клиентские WPF тесты.
