# Сообщения помощникам и кнопки супер администратора

Нужен клиент **1.2.3 или новее**. MSI устанавливается вручную либо распространяется через SCCM по общей инструкции; установленная служба получает подписанное обновление при очередной проверке. Адрес сервера и ключ клиента сохраняются.

## Отправка из веб-панели

1. Войдите с ролью **SuperAdmin** и откройте **Сообщения клиентам**.
2. Введите сообщение (до 1000 символов), задайте время показа (10–300 секунд).
3. Выберите компьютеры с помощью списка и поиска либо отметьте **Все зарегистрированные клиенты**.
4. Нажмите **Отправить**. Результат показывает, кому сообщение передано и какие ПК офлайн.
5. В **Журнале аудита** найдите команду `notice`: подтверждение клиента и текст результата появляются после обработки. `Completed` означает, что облачко создано или принято в очередь, согласно тексту результата; это не подтверждение прочтения сотрудником. `Offline` — ПК недоступен; автоматической отправки после его подключения нет. `Failed` — клиент не поддерживает показ или очередь заполнена; `TimedOut` — итоговый ответ не получен за пять минут.

Сообщение показывается над помощником в облачке с именем отправителя, переносом строк, прокруткой и кнопкой закрытия. Оно закрывается по таймеру. До десяти следующих сообщений ожидают в очереди; при первом запуске показ ждёт ответа на начальный вопрос помощника. Сохраняется обычный порядок окон помощника на рабочем столе; при перекрытии другими приложениями облачко может быть не видно.

## Привязка помощника

Откройте **Пользователи → Изменить**. Для роли **SuperAdmin** появляется поле **Помощник супер администратора**. Выберите зарегистрированный ПК и сохраните. Привязку может изменить только SuperAdmin; при смене роли на другую привязка очищается. Одна учётная запись привязывается к одному ПК; на общем ПК можно привязать несколько учётных записей SuperAdmin.

Изменение профиля отзывает прежний сеанс панели: потребуется повторный вход. На привязанном помощнике пункт **Кнопки супер админа** появляется после обновления доступности (до 30 секунд), подключения или обновления меню.

## Отправка из помощника

1. Нажмите помощника правой кнопкой мыши и выберите **Кнопки супер админа** (клиент 1.2.4 или новее). Здесь же находится **Закрыть помощника**. Левый клик открывает обычные кнопки.
2. Войдите под своей учётной записью панели: AD либо локальной. Пароль не сохраняется, токен существует только в памяти окна. После закрытия окна требуется новый вход.
3. Выберите настроенную кнопку/шаблон, отредактируйте текст, выберите всех или отдельные компьютеры и нажмите **Отправить сообщение**.

Сервер проверяет одновременно роль SuperAdmin, состояние учётной записи, привязку ПК и настоящий ключ подключённого помощника. Имя вошедшего в Windows пользователя, заявленное клиентом, само по себе не выдаёт полномочий. Отзыв привязки, роли или блокировка пользователя прекращают доступ.

## Кнопки супер админа

В одноимённом разделе панели создаются отдельные кнопки с названием, шаблоном текста, получателями по умолчанию (**Все** или **Выбор ПК**), временем показа, порядком и активностью. Пустой шаблон позволяет написать текст при отправке. Эта коллекция независима от обычных **Кнопок помощника** и содержит только действия отправки сообщений.

После изменения нажмите **Применить**; откройте окно супер администратора заново для загрузки актуального списка. В панели те же шаблоны доступны в разделе сообщений. Роли Admin, Operator, User и пользователи с отдельными правами на CMD/PowerShell не получают доступ к отправке и настройке этих кнопок.
