## 🚀 Текущий спринт: Автоматизация клиента и управление окнами

### 1. [x] Умный контроль запуска NCALayer (`NcaLayerWatchdog`)
- [x] **Задержка запуска ~7 минут:** При старте помощника выдерживается задержка 7 минут (`TimeSpan.FromMinutes(7)`), давая операционной системе полностью завершить фоновые службы и автозапуск.
- [x] **Проверка активного процесса:** Проверяется наличие процесса `ncalayer` в системе (`Process.GetProcessesByName("ncalayer")`).
- [x] **Исключение дублирования:** Если процесс уже активен — повторный экземпляр НЕ запускается, что полностью устраняет ошибку *«занят порт»*.
- [x] **Автозапуск при отсутствии:** Если процесса нет — находится исполняемый файл по стандартным путям системы и запускается `ncalayer.exe`.
- [x] **Оповещение при отсутствии программы:** Если `ncalayer.exe` не найден в системе — выводится локализованное уведомление пользователю: *«Приложение NCALayer не найдено в системе»* (с поддержкой RU, KK, EN, ZH).

---

### 2. [x] Проверка пользователей и очистка ресурсов (`SessionWatchdog`)
- [x] **Таймер проверки (2.5 минуты после старта):** Инспекция сессий стартует через 2.5 минуты после входа пользователя.
- [x] **Анализ активных сессий Windows:** Сессии определяются через Win32 `WTSEnumerateSessions` + `WTSQuerySessionInformation` и fallback-парсер `quser.exe`.
- [x] **Отключение пользователей в «ожидании»:** Если пользователей больше одного:
  - Определяется текущий активный пользователь на консоли.
  - Находятся сессии других пользователей в ожидании / отключении (например, заблокированная сессия `sadjan`).
  - Выполняется принудительное завершение неактивной сессии через `WTSLogoffSession` и `logoff.exe <Id>` для экономии памяти и ресурсов процессора.
  - Пользователю выводится уведомление: *«Завершена неактивная сессия пользователя {username} для освобождения ресурсов»*.
- [x] **Перезапуск NCALayer после очистки сессий:**
  - Проверяется процесс `ncalayer`: если остался от предыдущего пользователя или завис — принудительно завершается и перезапускается под текущим пользователем.
  - Если процесс не запущен — запускается `ncalayer.exe`.
  - Если приложение не найдено — пользователю показывается уведомление.
