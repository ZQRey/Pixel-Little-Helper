# Управление группами мессенджера

Доступно в веб-версии и клиенте начиная с 1.2.21. Права группы не связаны с ролью пользователя в Control Center.

| Действие | Участник | Администратор группы | Создатель |
|---|---|---|---|
| Переписка, просмотр участников | Да | Да | Да |
| Выход из группы | Да | Да | После передачи владения |
| Приглашение, изменение названия | Нет | Да | Да |
| Исключение и временное отключение обычных участников | Нет | Да | Да |
| Управление другими администраторами | Нет | Нет | Да |
| Назначение и снятие администраторов | Нет | Нет | Да |
| Передача владения, удаление группы | Нет | Нет | Да |

В GUI нажмите правой кнопкой по группе в списке чатов: «Настройки группы…», «Выйти из группы…», «Удалить группу…». В настройках или панели информации нажмите правой кнопкой по участнику для управления его доступом и ролью. В веб-версии используйте правую кнопку по группе → «Настройки группы…», а затем по участнику в панели информации.

Выход, исключение, временное отключение, изменение ролей, передача владения и удаление требуют подтверждения. Проверка прав выполняется сервером независимо от версии клиента.

Создатель не может исключить или отключить себя. Перед выходом он передаёт владение другому активному участнику. После передачи прежний создатель становится обычным участником. Администратор не может исключить или отключить создателя или другого администратора.

После исключения или выхода группа исчезает у пользователя; он не может получать новые сообщения или скачивать её файлы. При повторном приглашении сохраняется доступ к истории до выхода и к сообщениям после возвращения. Сообщения, файлы и события периода отсутствия недоступны. Назначенные ранее права администратора при возвращении не восстанавливаются.

«Удалить группу» скрывает её у всех участников и запрещает доступ к переписке и файлам через API. История, вложения, состав и журнал событий сохраняются на сервере. Это не физическое удаление данных. Старый API «close» сохраняет прежнюю возможность закрыть группу для записи; в новом интерфейсе вместо него используется «Удалить группу».

События группы показываются системными строками в переписке и журналом последних 50 событий в информации о группе. Они не увеличивают счётчик непрочитанных сообщений. Существующие группы после обновления сохраняют состав и создателей; остальные участники получают обычную роль.
