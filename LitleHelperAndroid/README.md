# Pixel Little Helper — Android Client (Pixel Anti-Theft)

Корпоративный Android-клиент для мобильных устройств (смартфонов и планшетов), входящий в экосистему **Pixel Little Helper**.

## Назначение
- **WireGuard VPN**: Автоматическое подключение устройства к корпоративному шлюзу (MikroTik) и изолированной подсети.
- **Pixel Anti-Theft**: Защита от кражи и утери:
  - Уровень 1: Экранный блокировщик поверх всех окон (`AntiTheftLockActivity`) с информацией об организации и контактами для возврата.
  - Уровень 2: Системная смена PIN через `DevicePolicyManager` и принудительная блокировка экрана (`lockNow()`).
  - Звуковая сирена поиска (`STREAM_ALARM` на 100% громкости).
  - Сбор и отправка телеметрии: GPS-координаты, Wi-Fi SSID/BSSID, уровень заряда батареи, статус SIM-карты.
- **Поддержка настроенных телефонов**: Устанавливается через USB (ADB) без необходимости сброса к заводским настройкам (сохраняет существующие аккаунты Google, Telegram и др.).

## Требования
- Android 8.0 (API 26) и выше.
- Gradle 8.2+, JDK 17+.

## Сборка
```bash
./gradlew assembleDebug
# или для релизной версии:
./gradlew assembleRelease
```
Собранный файл `.apk` помещается в директорию `LitleHelperServer/dist/android/PixelHelper.apk` для автоматической раздачи через веб-панель сервера.

## Автоматическая установка через USB (ADB)
Администратор скачивает архив установщика в веб-панели Helper (раздел «📱 Мобильные устройства» -> «📥 Скачать USB-установщик (ADB)») и запускает `setup-android.bat`.
Скрипт автоматически:
1. Ожидает подключения телефона с включенной отладкой по USB (`adb wait-for-device`).
2. Устанавливает APK: `adb install -r -g PixelHelper.apk`.
3. Активирует права администратора: `adb shell dpm set-active-admin com.pixelhelper.android/.DeviceAdminReceiver`.
4. Выдает фоновые разрешения (GPS, уведомления, оверлей поверх всех окон).
5. Отключает оптимизацию батареи (Doze).
6. Запускает приложение и считывает публичный ключ Curve25519 WireGuard, сразу копируя его в буфер обмена Windows.
